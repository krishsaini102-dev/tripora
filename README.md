# Tripora App
Mobile-first PWA-style travel booking app. Open index.html or serve the folder with any static server.

Included: app shell, bottom navigation, profile, bookings, offers, 5 travel search modes, 20+ travel tools and 50+ user-facing capabilities across the UI, localStorage persistence, dark mode, responsive desktop layout, geolocation, live Open-Meteo weather and live Frankfurter currency conversion.

Production integrations still require provider credentials/contracts: Firebase Auth/Firestore, flight/hotel/train/bus inventory APIs, payment gateway, maps/places, real-time PNR/transport feeds, notifications and backend security. Public demo APIs are used only where available without keys.
